# Changelog

## 0.3.0-preview.3 - 2026-10-09

- Add stable-ID structural remapping and targeted single/bulk content refresh.
- Add lease tokens, separate from content binding tokens.
- Add explicit batched immediate fragment demand, dependency-aware realization and hidden optional-fragment trimming.
- Preserve interaction gates across missing/destroyed templates and binding changes.
- Ship the playable SLG Armory business as an optional UPM sample, not a runtime dependency.
- Add resource-consuming upgrades, mixed one-shot rewards and checked backup recovery in the sample.
- Isolate diagnostic workloads from player progress and restore input after export failures.
- Add package-level architecture, migration, senior-interview and validation documentation.
- Verify tarball installation separately from the embedded-package development project; exact results accompany each release.
- Declare built-in sample diagnostic modules explicitly and guard rebinds triggered by hiding fragments.
- Mirror generated sample files instead of retaining obsolete exports.

## 0.2.0-preview.1 - 2026-10-08

- Freeze each scheduler frame's candidates; keyed updates and continuations preserve the newest request.
- Isolate task, readiness and cleanup failures. Dirty fields remain available for an explicit retry.
- Add scope-owned cleanup, binding generations and critical-state/layout/fragment interaction gates.
- Add dependency-validated lazy fragments and keep required dependency chains eligible during overload.
- Stage pooled instances under an inactive root, validate ownership and cap retained counts.
- Schedule fixed-grid/list creation; refresh same-ID content and recover obsolete range requests.
- Handle synchronous/stale sprite callbacks and one-shot cancellation/release cleanup.
- Add standalone minimal integration, editor diagnostics, automated regressions and Unity 2022.3 validation.
- Ship a separate equipment inventory with full-creation, conventional pooling and framework modes.

This is a Windows-validated preview. See the delivery scope for features not implemented and production validation still required. No license or public-distribution permission is inferred from the original archive.
