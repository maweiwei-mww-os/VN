# Minimal integration

Import this sample through Package Manager. Create an empty scene, add an empty GameObject, attach MinimalIntegrationDemo, and enter Play. It creates a scrolling list of 2000 logical items with bounded real views and shared scheduling. No inventory business assembly, external art or asset package is needed.

Production integration normally uses serialized prefabs and the project's existing canvas. This sample constructs its hierarchy at startup so installation can be verified without hand-wiring references.
