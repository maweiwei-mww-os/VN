# HighPerfUI 实测报告

日期：2026-10-08。结论来自 `Benchmarks/release-1000`，不是预设收益。

## 环境与协议

- Unity 2022.3.60f1c1，Windows x64 Mono Development Player。
- Windows 11 (10.0.26200)，AMD Ryzen 5 6600H，NVIDIA GeForce RTX 3050 Laptop GPU。
- 1440 x 900 窗口、VSync 关闭、120 FPS 上限，正常可见窗口运行；测试期间未同时进行 Unity 编译或归档压缩。
- 固定种子 1729、1000 件装备、每轮 1200 个脚本负载帧，另包含打开期间采样帧。
- 打开、来回滚动、每 30 帧批量修改战力、中途选中/穿戴/强化、最后回到顶部等待图标完成，是同一条组合轨迹。
- A/B/C 每组 10 次独立进程，轮次顺序轮换。全部 30 次退出 0，业务状态、实际网格像素和结果完整性验证通过。
- 30 次最终业务摘要相同：`f51196a88b0e34c2`。没有删除失败轮或选择最好的一轮；本次正式目录没有失败轮。

GC 累计量的中位数可能出现 .5，因为每组有偶数次实验；不表示实际分配半个字节。末端托管占用受 GC 时机影响，不代表全进程驻留。

## 可以得出的结论

**最大收益先来自常规列表虚拟化。** B 已把 1000 个完整 Item 限制为 40 个活动 Item，大幅降低全量创建和遍历负担。这部分不能全部归功于 C 的新增框架。

**C 相对 B 减少了约 26.8% 的集合节点，但存在代价。** 首屏中位数增加约 50.8%，GC 累计中位数增加约 4.7%。C 的片段创建次数更多、每次结构更小，不能拿 Instantiate 调用次数单独代表创建成本。

**本机 C 的 P99 较低，但不能直接宣称通用帧率胜出。** B/C 的 P95 均已接近 120 FPS 限制造成的 8.33ms 平台，差值不足以证明纯 CPU 收益。没有纯主线程 CPU 采样、消融和移动真机数据，不做更广泛推断。

**2ms 不是硬保证。** C 在这 10 轮中的最大单步为 14.7859ms，最大一次调度为 15.8016ms。预算只能控制工作边界；原生调用和系统停顿会超支。打开/启动附近的大帧也保留在原始记录中，不通过只看稳态 P95 隐藏。

C 最终节点范围为 616~730，原因是跨帧调度下实际曾创建并保留的可选片段数量随执行进度变化；业务最终状态一致不意味着缓存占用必须逐字节一致。报告使用全部轮次中位数，没有选择最小值充当固定上限。

## 测量边界

- 首屏计时从装备集合打开开始，公共壳层和共享图标已准备，不包含 Unity 进程启动，也没有清空 OS/GPU 缓存。
- 帧间隔样本包含打开过程以及脚本组合轨迹，不是单独滚动的分布；首个采样间隔也可能覆盖公共启动工作。
- A/B 不通过自定义调度器完成创建，它们的 MaxSchedulerMs 近零不能解释为创建几乎免费。
- 目前没有单独的 Canvas/Layout/Render 归因、GC 收集次数、每场景 CPU、冷/热打开完整分离、全量消融、功耗或长期内存回归。
- 使用开发构建和一台 Windows 笔记本；后台系统噪声、温度和频率未完全控制。未建立发布级性能 SLA，因此本版标记为技术预览。
- `pilot-1000` 是试测；`smoke-300` 是曾因隐藏窗口造成黑屏的无效早期实验。两者均不混入本报告。原目录保留供追溯。
- `Benchmarks/viewports` 的 1920x1080、1280x800 为 180 帧视觉/语义冒烟，已检查实际截图无裁切；不是 10 轮性能证据。

## 建议的面试结论

“我先用合理的循环网格和对象池作为基线，避免把常规优化收益算成新框架成果。完整框架进一步减少可选结构，并处理跨帧、复用和异步的一致性；但本次基准也暴露了首屏和分配开销，所以适合可选结构昂贵的热点，不建议无差别替换全部 UI。”

下一轮优化应针对 C/B 暴露的问题做单项消融：先分离片段创建、分帧等待、状态提交各自开销，再决定是否减少短生命周期分配和重复需求扫描。不能预先承诺优化后一定超过 B。

## 复核入口

`Benchmarks/release-1000/summary.json` 为摘要；每个 `mode-*.json` 对应一轮的环境与结果，同名前缀 CSV 为逐帧样本、PNG 为实际截图。`attempts` 记录全部进程轮次。

```powershell
./Tools/ValidateResults.ps1 -Output ./Benchmarks/release-1000 -Repeats 10 -Count 1000 -Frames 1200
```

完整重跑命令见 Operations.md。比较不同版本时需要重新固定构建和测试环境，不跨配置混算收益。
