# 0.2.0-preview.1 交付范围

这是可安装框架、业务参考工程和可复现实验的交付版，不是对最初“终极框架”全部概念的完成声明。

## 已实现并有测试

- 四级协作式预算调度、帧快照、结构化键合并、取消、异常隔离、队列年龄、过载时丢弃非关键任务。
- 类型化状态与 Dirty 合并，异常后保留待同步字段；独立有序命令队列。
- Scope 清理注册、Binding 代际、状态/布局/关键片段交互门禁。
- 可选模板懒创建、纯查询不创建、依赖图校验、关键依赖过载时仍完成、重绑不复活旧需求。
- 安全准备与有界池、固定列表/网格、同 ID 内容刷新、旧范围请求撤销。
- 同步/异步资源回调、过期结果丢弃与消费者租约释放、清理异常隔离。
- 不依赖业务程序集的 UPM 包和最小示例，单独干净工程安装验证。
- 真实装备库业务与 A/B/C；独立进程、JSON/逐帧 CSV/截图/失败日志、业务映射和像素有效性检查。

## 没有冒充已实现的能力

| 原始概念/目标 | 当前边界 |
| --- | --- |
| Fiber / 任意函数抢占 | ExecuteStep 协作式续步，不能中断正在执行的 Instantiate 或用户函数 |
| 三阶段 Commit 引擎 | 状态提交、布局就绪、交互门禁；不是通用 Mutation/Layout/Passive Effects 引擎 |
| 通用树 Diff / 子树剪枝 | 类型化 Dirty 更新和可选片段；没有 React 式全树 reconciler |
| HOT/WARM/PROTO | 单池实例复用和可注入总闲置数量限制；没有三级缓存与字节预算 |
| 原型扫描/黑白名单 | 显式模板描述和依赖验证；没有任意 Prefab 自动安全转换 |
| 指定版本命令屏障 | Binding + 业务 readyPredicate；没有内建状态版本协议 |
| Pool LeaseId | 实例归属/重复归还检查；没有跨租借代际句柄 |
| 帧预算自适应 | 可配置固定预算与过载状态；不是经过设备学习的自适应控制器 |
| 商业资源链路 | Resources 适配与延迟模拟提供器；Addressables/AB/网络接入需项目适配 |
| 通用布局 | 固定高度列表和固定网格；没有变高瀑布流与复杂动画布局 |
| 完整性能实验体系 | 当前为打开+滚动+更新组合轨迹及重复独立进程；单场景分布、完整消融、真机功耗/长期内存仍待做 |
| 商业验证 | Windows Mono Development Player 单机实测；没有 IL2CPP 移动真机、线上故障/长期灰度证据 |

## 接入前需要确认

先在一个可选分支多、重复单元多的界面试点；和现有循环列表+池比较。必须测首次交互延迟、P95/P99、GC、节点、驻留内存，并给出 C/B 负收益。简单界面可以继续使用 B。

原输入包未声明可公开分发的明确许可证。当前仅按用户授权本地改造交付；对外发布/商业授权前确认原始代码权利归属。没有执行远程推送。
